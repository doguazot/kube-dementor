Scan configuration

Context

The kubeconfig context supplies the cluster and credentials for this scan. Only contexts available on the server are listed.

Namespace

Enter a namespace to limit collection. Leave it blank to attempt cluster-wide collection. If authorization blocks that, the scanner falls back to the context namespace and any namespaces it can enumerate. Coverage gaps are reported.

Mode

Discover maps reachable resources. Scan identifies misconfigurations. Exploit verifies findings at the selected level. Chain actively attempts escalation and may create test pods, inject debug containers and execute in pods.

Exploit level

In Exploit mode, Safe uses authorization checks, Read-only permits GET/LIST probes including secrets and tokens, and Intrusive adds server-side dry-run tests. This setting does not limit Chain mode's active escalation.

Display severity

This sets the initial results filter, not the collection scope. All severities are collected. Lower the filter in Results at any time to see medium, low or informational findings.

Threat profile

External uses the internet-facing or shared-cluster baseline. Internal trust lowers perimeter-dependent rules by one severity step. RBAC, container escape and known-exploited vulnerabilities keep their severity.

Hide false positives

Hide findings that verification proved are false positives. This does not turn an unverified finding into a clean result.

Safety guard

The guard restricts mutation requests. Chain always blocks DELETE but allows tracked test-pod creation, exec and ephemeral-container injection. Only the separate Cleanup action deletes tracked chain pods.

Disable safety guard

Removes guard restrictions for non-Chain scans. Use only on an authorized test cluster. This override does not disable Chain's mandatory DELETE protection.

Exclusions

            
            

              Exclusions
              
YAML or JSON. Every rule needs ruleId (exact) or ruleIdPattern (regex); optional filters: namespaces, resourceKinds, namePattern, severityMin (CRITICAL|HIGH|MEDIUM|LOW|INFO) and a documenting reason. The file is validated when you press Run scan — invalid files are rejected with the exact error. Chain mode ignores exclusions.

            

            Known-expected findings are filtered before they reach the report.
